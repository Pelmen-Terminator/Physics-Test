# Тест по физике

Онлайн-тест по школьной физике: механика, термодинамика, электричество и магнетизм, колебания и оптика, атомная и современная физика. Чистый HTML/CSS/JS, без сборки и зависимостей.

- 200 обязательных вопросов за одно прохождение, выбираются случайно из базы в 500 вопросов, без повторов
- 4 варианта ответа, порядок вариантов перемешивается
- оценка по 5-балльной системе
- шкала из 200 делений показывает ход теста
- клавиши 1–4 выбирают ответ, Enter переходит дальше
- светлая и тёмная темы (по настройкам системы)

## Запуск

Откройте `index.html` в браузере. Больше ничего не нужно.

## Публикация на GitHub Pages

1. Загрузите все файлы в корень репозитория.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | разметка трёх экранов: старт, тест, результат |
| `style.css` | оформление и темы |
| `script.js` | логика теста и оценка |
| `questions.js` | база вопросов |

## Настройка

- Количество вопросов в тесте: константа `QUESTIONS_PER_TEST` в начале `script.js`. Оно не должно превышать число вопросов в базе.
- Формат вопроса в `questions.js`: `{ n: номер, q: "вопрос", a: ["верный", "неверный", "неверный", "неверный"], c: 0 }`. Верный ответ всегда стоит первым, при показе варианты перемешиваются.
- Пороги оценок: функция `getGrade` в `script.js` (90% — «5», 70% — «4», 50% — «3»).
